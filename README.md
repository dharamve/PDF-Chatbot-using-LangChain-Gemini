# 📄 LangChain PDF Chatbot using Gemini

A beginner-friendly **Retrieval-Augmented Generation (RAG)** chatbot built using **LangChain, Google Gemini, ChromaDB, and Python**.

The application allows users to upload/use a PDF document and ask questions about its content. The chatbot retrieves relevant information from the PDF and sends it to Gemini to generate a natural-language answer.

---

## 🚀 Project Overview

Traditional chatbots answer questions using general knowledge. This project is different because it allows the chatbot to answer questions based on a **specific PDF document**.

For example:

> **PDF:** Company Annual Report
> **Question:** What was the company's revenue in 2025?
> **Answer:** The chatbot searches the PDF for relevant information and generates an answer using Gemini.

The project demonstrates the basic implementation of a **RAG pipeline using LangChain**.

---

## 🎯 Objectives

The main objectives of this project are:

* Learn the fundamentals of LangChain
* Understand Retrieval-Augmented Generation (RAG)
* Load and process PDF documents
* Split documents into smaller chunks
* Generate vector embeddings
* Store embeddings in ChromaDB
* Retrieve relevant document chunks
* Use Google Gemini to generate answers
* Build a simple command-line chatbot
